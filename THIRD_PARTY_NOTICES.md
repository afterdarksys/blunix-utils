## In release images: Debian 13 packages

The installer ISO, the disk image and the netboot media are built from binary packages in Debian 13 (trixie). The Linux kernel, GRUB, the GNU userland and many others are under the GNU GPL or LGPL. Others use BSD, MIT, Apache and similar licenses. Each package's own terms are installed at `/usr/share/doc/<package>/copyright` on the image.

Each GitHub release includes `SOURCES.md`, generated by `image/gpl-sources.py` from the image's own package database. It lists every source package and exact version, links each one to snapshot.debian.org, and carries a written offer for the corresponding source.
